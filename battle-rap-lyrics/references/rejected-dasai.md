# ダサいと言われたフレーズ

ユーザーに「ダサい」「最悪」「酷い」「パンチが弱い」「意味が分からない」と言われて、外したフレーズを集めた。
書く前に読み、同じ形のフレーズを出さない。

- ここの行は、外した行。そのまま使わない。似た形も使わない。
- 本人が分かる地名は「〇〇」に伏せた。

## 1. 地名や名所のだじゃれ、観光の絵はがきに頼る

言葉遊びの仕掛けが見えすぎて、安く聞こえる。

```
京都と聞けば 都
着いたら 雪の 〇〇
```

```
絵はがきなら 〇〇（名所）
俺には 雪の 立ち往生
```

- 地名の 1 音違いや、名所の名前の字を掛けるだけの行は書かない。

## 2. 「AなのにBは〜」の、気の利いたふうの対比

ひねった感じを出そうとした対比が、生活の不満を弱くしている。

```
ボンベは来るのに 業者は来ない
火はボンベ 呼べる手は無い
```

- 生活の不満は、対比で飾らずに本音を直球で言う。採用された形は「高すぎる」とそのまま言う行だった。

## 3. どこかで聞いた、きれいで中身の無い締め

歌詞らしく聞こえるだけで、何も言っていない。

```
届かない声 止まらない手
答え合わせは まだ先
居場所は もらうもんじゃない 組むもん
鍵かける手で 鍵のいらないもん作る
下げない頭 今度は俺の番
```

```
集中
格子の向こうは不自由
選んだ道は まだ途中
捨てた道は ひとつで十分
```

- 「まだ先」「まだ途中」「止まらない」「〜じゃない 〜もん」「今度は俺の番」のような決まり文句で締めない。
- 2 つ目のかたまりは、「変えてほしい」と言われた 4 行から、外した部分だけを抜き出したもの。韻をそろえるために、どこかで聞いた締めの言葉を並べていた。
- 同じ 4 行のうち、「制服脱げば 作るのに夢中」「俺の頭は自由」は、ユーザーが「残したほうがいいかも」と言って、短くした形で残した。外したフレーズではない。
- 仕事の道具と、作ることを掛ける行は、よく聞く形になる。

## 4. 弱い言い返し

相手に言い返す行が、おとなしくて当たらない。

```
そっちは 聞く耳が足りない
```

- 採用された形は「黙れよ お前は〜足りねえ」。相手に直接ぶつけ、語尾を崩す。

## 5. 意地の張り合いを、ことわざのように言う

```
頑固には頑固 根比べなら負けねえ
```

- 「〜には〜」「〜なら負けねえ」の形は、決まり文句に聞こえる。

## 6. 悲壮感で強さが薄れる

```
業者は来ねえ 春も来ねえ
```

- 戦っている曲で、季節や天気に頼って寂しさを出さない。強さが薄れる。

## 7. 説明だけの行、言い直すだけの行

```
決まってた線路を 降りて 別の道
辞める扉は 開いたまま
その扉に 背中 向けたまま
俺は 詫びの代わりに 割られた頭
学校と引っ越し 同じ日付
学のある俺から見れば お前らの理屈は穴だらけ
```

- 「別の道」は、どこへ行ったかが分からない。
- 扉の 2 行は、次の行の「それでも制服を着る」を別の例えで言い直しているだけだった。
- 「詫びの代わりに」は、説明の言葉。採用された形は「俺は 割られた頭」だけだった。
- 「学校と引っ越し 同じ日付」は、「微妙」と言われた。事実をそのまま並べただけで、絵も韻も無い。
- 「学のある俺から見れば」は、自分の賢さを言葉で言っている。

## 8. 日本語の意味を、英語で言い直すだけ

```
ノーブレーキ
エブリデイ
```

- 歌詞に英語が無いと言われて出した候補。どちらも、前の日本語の意味を英語で言い直しているだけで、韻の音も伸ばしていなかった。
- 英語は、続いている韻の音を伸ばすために選ぶ。意味が足されるなら、なお良い。

## 9. 行の中で踏んでいない

```
名前は練習 中身は暴行
止まらねえ拳 ただの横暴
```

- 行の終わりが前の行とそろっていても、1 行の中で踏んでいないと弱い。「イン踏んでない」と言われた。
- 1 行の前半と後半の言葉の母音をそろえる。採用された形は、前半の言葉を、後半と同じ母音の言葉に替えたものだった。

## 10. 母音だけで選んだ、意味の広い漢語で踏む

```
俺ならば 横文字抜きでも 大好評
お前は 口先だけの 大統領
```

- 行の終わりの母音は 6 個そろっていたが、「ださい」と言われた。
- 「大好評」「大統領」は、「あ・い・お・お」で終わる言葉を、辞書のように探して当てはめただけだった。誰の歌詞にでも入り、絵が浮かばない。
- 「大好評」は、自分の評判を自分で言う言葉で、イキって聞こえる。
- 見本にされた長い韻は、人の名前、キャリアの年数、グループの名前のような、その人にしか言えない事実で踏んでいた。長い韻の言葉は、名前、物、数字から作る。

## 11. 同じ言葉で踏み続ける

```
来たのは 黒船
勝てるか 黒船
```

- 同じ言葉を 2 行の終わりに置いただけで、韻を作っていない。「連呼は止めてほしい」と言われた。
- 同じフレーズをくり返してよいのは、フックだけ。

## 12. 助詞が多い

```
コンサルの パワポで ミッキーが歌ってる
カプコンの 数式 一行に 意味がつまってる
```

- 「助詞入れすぎ」と言われた。2 行に助詞が 7 つあった。
- 削っても意味が通じる助詞は、7 割ほど削る。

## 13. 頼まれた文の言葉を、そのまま歌詞に書く

```
コンサル パワポ ミッキーが歌ってる
カプコン 数式 一行 意味がつまってる
```

- 「直球すぎる」と言われた。「コンサル」「パワポ」「カプコン」「数式」は、頼まれた文の言葉そのものだった。
- 実例は、何の話かを言葉で言わず、その世界の物と名前で伝えている。

## 14. 置き換えた物と、言いたいことのつながりが聞き手に分からない

```
ロレックス シナジー ミッキーが歌ってる
```

- 「意味が分からない」と言われた。
- 書いた側のつもりは、ロレックスは高い時計を着けるコンサル、シナジーはコンサルがよく言う横文字、ミッキーは中身の無い派手なショーだった。つながりは書いた側の頭の中にしか無く、聞き手には届かなかった。
- 実例の置き換えは、聞いてすぐつながりが分かる。大谷翔平は一番の選手、パトカーは警察に追われる暮らし。つながりを、多くの人がうなずく短い文で言えない物は使わない。
