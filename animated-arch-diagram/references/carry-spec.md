# carry-spec.js の書式（運搬型）

`window.SPEC = { ... }` に「駅」と「出来事の並び」を書く。座標の計算・折り返し・時刻の計算は carry.js がやる。
見本は 2 つ。
- `assets/template/carry-spec.js`：レシートの写真が家計簿の 1 行になるまで（一方通行。入口の場面・3 行の吹き出し・処理の絵 4 つを全部使う）
- `assets/template/examples/carry-loop-spec.js`：問い合わせチャットが返事を作るまで（2 周のループ）

## 全体

| 項目 | 必須 | 意味 |
|---|---|---|
| `title`, `subtitle` | | 左上の見出しと、その下の一行（追った具体例を書く。例:「〜を 1 つ流した例」） |
| `flow` | | 書かなければ一方通行（左から右へ流れて終わる）。処理が最初の段へ戻るときだけ `'loop'` |
| `opening` | ✓ | 入口の場面。何を、何に変える物かを 1 枚で見せる（下記） |
| `row` | | 駅を並べる高さ（1600×900 の論理座標）。既定 560。上に吹き出し、下に戻り道が入る |
| `theme` | | `{ bg, card, fg, dim, edge, dot, font }` の一部だけ上書きできる |
| `stations` | ✓ | 駅。左から右へ、処理の順に並べる |
| `paths` | ✓ | 駅と駅を結ぶ線 |
| `beats` | ✓ | 出来事の並び。上から順に再生する |
| `outro` | | `{ kicker, caption, hold, loop, flow }`。締めの小見出し・一言・滞在秒。一方通行は左から右へ 1 回だけ光が流れて止まる（`flow` で流す線の id を選べる）。ループは `loop` に並べた線に光を流し続ける |
| `poster` | | ポスター画像を撮る秒（既定: 締めの 1 秒後） |

## opening

```js
opening: {
  from: { label: 'レシートの写真', sub: 'スマホで撮った 1 枚', color: ME, kicker: '入れる物' },
  to: { label: '家計簿の 1 行', sub: '日付・お店・金額', color: NEW, kicker: 'できる物' },
  via: '家計簿アプリ', caption: '家計簿アプリは、レシートの写真を家計簿の 1 行に変える', dur: 3.6,
}
```

- `from` は入れる物、`to` はできる物。見る人が知っている物の名前で書く（ファイル形式やデータの名前にしない）
- `via` は、変える物（ツールやアプリ）の名前。矢印の上に出る
- `caption` は「〈ツール〉は、〈入れる物〉を〈できる物〉に変える」の形。主語から書く

## stations

```js
{ id: 'p2', label: '② 判断して答える', sub: 'AI', color: '#f59e0b', x: 725, w: 230 }
```

- `x` は駅の中心（論理座標、横 1600）。5 駅なら 105 / 385 / 725 / 1065 / 1405 が収まりがよい（駅どうしの間隔 340）
- `sub` に役割（AI / プログラム / 人 など）を書き、**同じ役割は同じ色**にする。凡例を出さなくても色で役割が分かる
- 番号（① ② …）を label の頭に付けると、字幕や吹き出しから「① へ戻る」のように呼べる

## paths

```js
{ id: '23', from: 'p2', to: 'p3', kind: 'line' }
{ id: 'back', from: 'p4', to: 'p1', kind: 'under', depth: 130, dx: [-50, 0], label: '返事がまだなら、① へ戻る' }
```

- `line`: となりの駅へまっすぐ（右の辺から左の辺へ）。一方通行はこれだけを使う
- `under`: 駅の下を回る曲線。`flow: 'loop'` のときの戻り道にだけ使う。`depth` は深さ（曲線の底は depth × 0.75 下）、`dx` は出る位置と入る位置の横のずらし
- 戻り道が 2 本あるとき（「① へ戻る」と「外へ出す」など）は、外側の線ほど深く・出口を外側にずらして入れ子にする。交差させない
- `label` は曲線の底の下に出る。どんな条件でその道を通るかを文で書く（「戻る」だけにしない）

## beats

駅での出来事（`at`）、処理の絵（`scene`）、線の上の移動（`move`）を、「駅 → 処理の絵 → 移動」の順に並べる。

```js
{ at: 'p3', dur: 4.4, loop: 1, kicker: '1 周目', caption: 'プログラムが、規約を検索する',
  out: { text: '見つけた規約', color: '#34d399' },
  bubble: { title: 'プログラムが処理する', lines: [{ text: '規約を検索', bold: true }, { text: '→ 返品の節 2 つ', color: '#34d399' }] } },
{ move: '34' },
```

| 項目 | 意味 |
|---|---|
| `at` | 札がいる駅。滞在中は駅が光り、駅の中の細い棒が進む（処理中） |
| `dur` | 滞在秒（既定 3）。`move` の場合は移動の秒（既定 1.0。戻り道は 1.8〜2.0）。`scene` の場合は絵を見せる秒（既定 2.4） |
| `loop` | 何周目か（ループのときだけ）。`keep: 'loop'` の吹き出しは、同じ周のあいだ薄くして残し、周が変わると消える |
| `scene` | 処理の絵（下記）。`at` と同じ出来事には書かず、駅の出来事の次に別の 1 つとして並べる |
| `kicker` | 右上の小見出し（「1 周目」など）。次に書くまで出し続ける |
| `caption` | 下の字幕（タイプライター）。1 文 25 字前後。次に書くまで出し続ける |
| `out` | この駅から出ていく札の `{ text, color }`。次の `move` で運ばれる。**札の名前は、中身が変わるたびに変える** |
| `move` | 線の id。直前の駅の `out` がこの線を運ばれる |
| `bubble` | 駅の上の吹き出し（下記） |

## bubble

基本は 3 行の型。見出しの下に「受け取る」「すること」「渡す」の 3 行が並ぶ。

```js
bubble: { title: 'AI が見分ける', take: '読み取った文字', act: 'どれが日付・お店・金額かを決める' }
// 渡す（give）を省くと、この駅の out（札）と同じ言葉になる
```

| 項目 | 意味 |
|---|---|
| `title` | 吹き出しの見出し（「だれが・何をする」の形。例: AI が見分ける） |
| `take` | 受け取る物。前の駅の札と同じ言葉にする。最初の駅（人など）は省いてよい |
| `act` | すること。1 文で、見る人の言葉で書く |
| `give` | 渡す物。省くと `out.text` になる。書くときも札と同じ言葉にする（違うと check が止める） |
| `w`, `dx` | 幅（3 行の型は既定 460、`lines` は既定 330）と横のずらし。となりの吹き出しと重なるときは `dx` でずらす |
| `keep` | `'next'`（既定: 次の駅に着いたら消す）か `'loop'`（同じ周の終わりまで薄くして残す） |
| `lines` | 3 行の型の代わりに、行を自由に並べる。check が止めるので、使うのは `groups` と組むときだけ |
| `groups` | 囲みごとに分けて並べる（下記） |

行（line）の項目: `text`、`at`（吹き出しが出てからの秒。既定は 0.5 秒おき）、`bold`、`color`、`dim`（薄く）、`size`（既定 22）、`indent`、`hang`（2 行目からの字下げ px）、`gap`（上の空き px）、`mark`（色の帯で目立たせる）。
折り返しは実際の文字幅を測って行う。行頭に句読点や閉じかっこは置かない。

### groups（囲み）

渡すものの「構造」を見せたいときに使う。例えば、毎回同じ指示と、話すたびに増える会話を分ける。

```js
groups: [
  { label: '毎回同じ指示（はじめに渡す決まり）', color: PG, fly: '毎回同じ指示',
    lines: [{ text: '応対の決まり：話し方と、確かめる順番', size: 19 }] },
  { label: '会話の記録（話すたびに増える）', color: CU, fly: '会話の記録', dashed: true,
    lines: [{ text: 'お客様：靴を返品したい', size: 19 }] },
]
```

- `label` は囲みの見出し。「何か（どういうものか）」の形で書く
- 変わらないものは実線、増えていくものは `dashed: true`（点線）
- `fly` を付けると、囲みの中身がその名前の小さな札になって駅に吸い込まれる（「まとめて渡す」動き）
- 2 周目以降は、前の周と同じ行を `dim: true` にし、新しく増えた行だけ `mark: true` で光らせる

## scene（処理の絵）

駅の出来事の次に `{ scene: {...}, dur, caption }` を 1 つ並べる。絵のあいだ、図は暗くなる。`title` は絵の上の見出し（何をしている絵か）。

```js
{ scene: { kind: 'fetch', title: '写真から、文字だけを取り出す', from: [{ label: 'レシートの写真', color: ME }],
    items: ['ベーカリー森', '2026/10/05', '合計 640円'], to: { label: '読み取った文字', color: PG } },
  dur: 2.6, caption: '店名・日付・値段が、ただの文字の並びになる' },
```

| kind | 項目 |
|---|---|
| `fetch` | `from`: 取ってくる先（1〜3 個）、`items`: 取ってくる物（2〜5 個。実データの例）、`to`: 集めた物の名前 |
| `merge` | `a`, `b`: 合わせる 2 つ（`label` と `items`）、`to`: 合わせてできる物（`label` と `items`） |
| `transform` | `from`, `to`: 変わる前と後（`label`、`note`）。`via`: 矢印の上の言葉。`poly`: 輪郭の形（0〜1 の点の並び。既定は L 字）、`cells`: マス目の細かさ（既定 12） |
| `stack` | `layers`: 下から積む層（2〜5 個。`label` と `color`）、`label`: 積み上がった物の名前 |

- 文字の項目は、文字列か `{ label, color }` のどちらでも書ける
- 4 つに合う物が無いときは、別の kind を代わりに使わない。部品の不足として報告する（check も止める）

## 時刻表と確認

```powershell
node tools/render.mjs check --page carry.html   # 書き出す前の確かめ。通らない所を一覧にして止まる
node tools/render.mjs info --page carry.html
node tools/render.mjs sheet 16 --page carry.html
node tools/render.mjs stills 12.5,30.2 --page carry.html
node tools/render.mjs video <名前> --page carry.html   # check が通らないと書き出さない
```

ループの見本を見るときは、どのコマンドにも `--spec examples/carry-loop-spec.js` を付ける。

stills は、**各滞在の終わり近く**（全部の行が出そろった時刻）を撮って見る。滞在の途中では行がまだ出ていない。
