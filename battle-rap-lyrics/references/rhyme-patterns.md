# 長い韻の数え方と作り方

ここの例文は、形を見せるために作ったもの。歌詞にそのまま使わない。

## 1. 母音の数え方

日本語の韻は、言葉の母音をそろえて作る。子音は違っていてよい。
韻は、字ではなく、ラップで口に出したときの音で数える。字のまま数えると、聞いて気持ちいい長い韻を見落とす。

| 音 | 数え方 | 例 |
|---|---|---|
| 小さい「ゃ ゅ ょ」 | 前の字と合わせて 1 つ。母音は小さい字のほう | 「きょ」は「お」 |
| 伸ばす音（「ー」、「そう」の「う」、「せい」の「い」） | 飛ばす | 「蒼白」は「そーはく」で「お・あ・う」 |
| 「っ」「ん」 | 飛ばす | 「洗濯」は「え・あ・う」 |
| 英字で書いた英語 | 語の終わりの子音は飛ばす | 「Respect」は「りすぺ」 |
| 英字の略語 | 読みに直してから数える | 「AI」は「えーあい」で「え・あ・い」 |

英語のつなげ読みと、わざと崩した言い方は、字からは分からない。行の後ろに「｜」を置き、口で言う読みをひらがなで書く。

- 例は `Check it out｜ちぇけらう`、`Rap Boys｜らっぼーい`。
- カタカナで書いた英語は、字のとおりに数えられてしまう。英語の行は、英字で書くか、「｜」で読みを書く。
- 伸ばす音は「ー」で書く。言葉の切れ目には、空白を入れる。

## 2. スクリプトの印

`uv run scripts/check_rhyme.py <歌詞のファイル>` は、行ごとに読みと母音を出し、次の 3 つの印を付ける。

| 印 | 中身 |
|---|---|
| 終わり ◎ | 前の行と、行の終わりから母音が 3 個以上そろう |
| 長い韻 ★ | 3 行前までの行と、母音が 5 個以上続けてそろう |
| 行の中 ◎ | 同じ行の 2 か所で、母音が 3 個以上続けてそろう |

`--words <言葉> <言葉> ... --target <読み>` を付けると、言葉ごとの読みと母音を出し、target と長くそろう順に並べる。

## 3. 母音を 6〜7 個そろえる

母音を 6〜7 個持つ言葉は、1 語では少ない。「名詞＋名詞」「形容＋名詞」「名詞＋動き」のように、2〜3 語のかたまりで踏む。かたまりの中の助詞は、SKILL.md の「助詞」の決まりで削る。
実例の作り方は 6 つあり、`analysis.md` の 2 章にある。

作る手順は次のとおり。

1. 山にしたいかたまりを決め、`--words` で母音を出す。
2. 同じ母音の並びになりそうな言葉を、話と関係ない世界からも 10 個以上集める。世界の例は、スポーツ選手、歴史の人、三種の神器のような決まった組の言葉、アニメ、ブランド、食べ物、乗り物。その世界の人が好きな物は `analysis.md` の 4 章にある。
3. 集めた言葉の前に 1 語を足して、かたまりの候補を作る。
4. 候補を `--target` にかけ、6 個以上そろうものだけを残す。
5. 残った中から、聞いて面白い言葉と、聞き手の多くが知っている言葉を選ぶ。
