# carry-spec.js の書式（運搬型）

`window.SPEC = { ... }` に「駅」と「出来事の並び」を書く。座標の計算・折り返し・時刻の計算は carry.js がやる。
見本は `assets/template/carry-spec.js`（架空の問い合わせチャット、2 周のループ）。

## 全体

| 項目 | 必須 | 意味 |
|---|---|---|
| `title`, `subtitle` | | 左上の見出しと、その下の一行（追った具体例を書く。例:「〜を 1 つ流した例」） |
| `row` | | 駅を並べる高さ（1600×900 の論理座標）。既定 560。上に吹き出し、下に戻り道が入る |
| `theme` | | `{ bg, card, fg, dim, edge, dot, font }` の一部だけ上書きできる |
| `stations` | ✓ | 駅。左から右へ、処理の順に並べる |
| `paths` | ✓ | 駅と駅を結ぶ線 |
| `beats` | ✓ | 出来事の並び。上から順に再生する |
| `outro` | | `{ kicker, caption, hold, loop }`。締めの小見出し・一言・滞在秒・光を流す線の id の並び |
| `poster` | | ポスター画像を撮る秒（既定: 締めの 1 秒後） |

## stations

```js
{ id: 'p2', label: '② 判断して答える', sub: 'AI', color: '#f59e0b', x: 725, w: 230 }
```

- `x` は駅の中心（論理座標、横 1600）。5 駅なら 105 / 385 / 725 / 1065 / 1405 が収まりがよい（駅どうしの間隔 340）
- `sub` に役割（AI / プログラム / 人 など）を書き、**同じ役割は同じ色**にする。凡例を出さなくても色で役割が分かる
- 番号（① ② …）を label の頭に付けると、字幕や吹き出しから「① へ戻る」のように呼べる

## paths

```js
{ id: '23', from: 'p2', to: 'p3', kind: 'line' }
{ id: 'back', from: 'p4', to: 'p1', kind: 'under', depth: 130, dx: [-50, 0], label: '返事がまだなら、① へ戻る' }
```

- `line`: となりの駅へまっすぐ（右の辺から左の辺へ）
- `under`: 駅の下を回る曲線。ループの戻り道に使う。`depth` は深さ（曲線の底は depth × 0.75 下）、`dx` は出る位置と入る位置の横のずらし
- 戻り道が 2 本あるとき（「① へ戻る」と「外へ出す」など）は、外側の線ほど深く・出口を外側にずらして入れ子にする。交差させない
- `label` は曲線の底の下に出る。どんな条件でその道を通るかを文で書く（「戻る」だけにしない）

## beats

駅での出来事と、線の上の移動を交互に並べる。

```js
{ at: 'p3', dur: 4.4, loop: 1, kicker: '1 周目', caption: 'プログラムが、規約を検索する',
  out: { text: '見つけた規約', color: '#34d399' },
  bubble: { title: 'プログラムが処理する', lines: [{ text: '規約を検索', bold: true }, { text: '→ 返品の節 2 つ', color: '#34d399' }] } },
{ move: '34' },
```

| 項目 | 意味 |
|---|---|
| `at` | 札がいる駅。滞在中は駅が光り、駅の中の細い棒が進む（処理中） |
| `dur` | 滞在秒（既定 3）。`move` の場合は移動の秒（既定 1.0。戻り道は 1.8〜2.0） |
| `loop` | 何周目か。吹き出しは、同じ周のあいだ薄くして残し、周が変わると消える |
| `kicker` | 右上の小見出し（「1 周目」など）。次に書くまで出し続ける |
| `caption` | 下の字幕（タイプライター）。1 文 25 字前後。次に書くまで出し続ける |
| `out` | この駅から出ていく札の `{ text, color }`。次の `move` で運ばれる。**札の名前は、中身が変わるたびに変える** |
| `move` | 線の id。直前の駅の `out` がこの線を運ばれる |
| `bubble` | 駅の上の吹き出し（下記） |

## bubble

```js
bubble: { title: 'AI が判断して答える', w: 330, dx: 0, color: '#f59e0b', keep: 'loop',
  lines: [ { text: '答え：返品の規約を探す', bold: true, color: '#f59e0b' }, ... ] }
```

| 項目 | 意味 |
|---|---|
| `title` | 吹き出しの見出し（「だれが・何をする」の形。例: AI が判断して答える） |
| `w`, `dx` | 幅（既定 330）と横のずらし。となりの吹き出しと重なるときは `dx` でずらす |
| `keep` | `'loop'`（既定: 周の終わりまで残す）か `'next'`（次の駅に着いたら消す） |
| `lines` | 行の並び。行は 2〜4 行に抑える |
| `groups` | `lines` の代わりに、囲みごとに分けて並べる（下記） |

行（line）の項目: `text`、`at`（吹き出しが出てからの秒。既定は 0.5 秒おき）、`bold`、`color`、`dim`（薄く）、`size`（既定 22）、`indent`、`hang`（2 行目からの字下げ px）、`gap`（上の空き px）、`mark`（色の帯で目立たせる）。
折り返しは実際の文字幅を測って行う。行頭に句読点や閉じかっこは置かない。

### groups（囲み）

渡すものの「構造」を見せたいときに使う。例えば、毎回同じ指示と、話すたびに増える会話を分ける。

```js
groups: [
  { label: '毎回同じ指示（はじめに渡す決まり）', color: PG, fly: '毎回同じ指示',
    lines: [{ text: '応対の決まり：話し方と、確かめる順番', size: 19 }] },
  { label: '会話の記録（話すたびに増える）', color: CU, fly: '会話の記録', dashed: true,
    lines: [{ text: 'お客様：靴を返品したい', size: 19 }] },
]
```

- `label` は囲みの見出し。「何か（どういうものか）」の形で書く
- 変わらないものは実線、増えていくものは `dashed: true`（点線）
- `fly` を付けると、囲みの中身がその名前の小さな札になって駅に吸い込まれる（「まとめて渡す」動き）
- 2 周目以降は、前の周と同じ行を `dim: true` にし、新しく増えた行だけ `mark: true` で光らせる

## 時刻表と確認

```powershell
node tools/render.mjs info --page carry.html
node tools/render.mjs sheet 16 --page carry.html
node tools/render.mjs stills 12.5,30.2 --page carry.html
node tools/render.mjs video <名前> --page carry.html
```

stills は、**各滞在の終わり近く**（全部の行が出そろった時刻）を撮って見る。滞在の途中では行がまだ出ていない。
