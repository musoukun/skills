# scenes.js の書式

承認をもらった台本（`references/storyboard.md`）を、`scenes.js` に書き移す。
`window.SCENES = { ... }` に、場面を上から順に並べる。
時刻の計算、カメラ、場面の切り替え、字幕は `core.js` がする。
場面の中身は、場面ごとに選んだ部品（`parts/`）が描く。

## 全体

| 項目 | 必須 | 意味 |
|---|---|---|
| `scenes` | ✓ | 場面の並び。上から順に流れる |
| `theme` | | `{ bg, card, fg, dim, edge, accent, font, mono }` の一部だけ変えられる |
| `fps` | | 既定 30 |
| `poster` | | ポスター画像を撮る秒。既定は動画の真ん中 |

## 場面

```js
{
  part: 'blocks', dur: 5.0, kicker: '仕組み', caption: '毎回同じ指示に、会話の記録を足して AI に渡す', color: '#f59e0b',
  transition: { type: 'expand', from: 'input' },
  camera: [{ at: 0.5, to: 'input', fit: 0.6, dur: 0.8 }, { at: 3.2, dur: 0.7 }],
  blocks: [ ... ],   // 部品ごとの中身（下の「部品」）
}
```

| 項目 | 意味 |
|---|---|
| `part` | 場面を描く部品の名前（`parts/<名前>.js`）。`index.html` で読み込む |
| `dur` | 場面の長さ（秒）。切り替えの時間も含む |
| `kicker` | 字幕の小見出し（操作 / 仕組み / 全体の形 / まとめ など） |
| `caption` | 字幕の 1 行。1 字ずつ出る。25 字前後まで |
| `color` | 小見出しと、切り替えの枠の色 |
| `bg` | 場面の背景の色（既定は `theme.bg`） |
| `transition` | 前の場面からの切り替え（下） |
| `camera` | カメラの動き（下） |

場面の中の時刻（部品が使う `at` など）は、場面の始まりから数える。
切り替えの時間も場面に含まれるので、中身は切り替えが終わってから出す（expand なら 0.8 秒より後）。

## 切り替え（transition）

| type | 動き | 使う場面 |
|---|---|---|
| `cut` | すぐ切り替わる（既定） | |
| `fade` | 前の場面が消え、次の場面が出る（0.5 秒） | 締めに入るときなど |
| `expand` | 前の場面の中の要素（`from`）が、画面いっぱいに広がって次の場面になる（0.8 秒）。Mac の全画面の切り替えのような動き | 操作から仕組みに入るとき。送った文字などを引き出す |
| `collapse` | 前の場面が縮んで、次の場面の中の要素（`to`）に戻っていく（0.7 秒） | 仕組みから操作に戻るとき。結果が画面のどこに出たかを見せる |

- `from` と `to` は、要素に付けた `id`（部品が `data-anchor` にするもの）。
- `dur` を書くと、切り替えの時間を変えられる。
- expand では、次の場面の真ん中あたりが、`from` の四角の中から広がって見える。引き出したもの（送った文字など）を、次の場面の真ん中に置くと、つながって見える。

## カメラ（camera）

上から順に進む。前の動きが終わってから次を書く（時間を重ねない）。

| 項目 | 意味 |
|---|---|
| `at` | 動き始める秒（場面の始まりから） |
| `to` | 寄る先の要素の `id`。書かなければ全体に戻る |
| `fit` | 寄る先が画面の幅のどれくらいを占めるか（0.6 なら 6 割） |
| `zoom` | 倍率で決めるとき（`fit` の代わり） |
| `dur` | 動く時間（既定 0.7 秒） |

画面の外（何も無い所）は映らないように、寄る位置を自動でずらす。
寄った先が画面の端に来ることがあるので、止めた絵で確かめる。

## 部品

### blocks（座標で置くだけの部品）

```js
blocks: [
  { kind: 'window', light: true, title: 'サポートチャット', x: 330, y: 90, w: 940, h: 640 },
  { kind: 'input', light: true, id: 'input', x: 380, y: 640, w: 700, h: 60 },
  { kind: 'text', text: '先週届いた靴を返品したい', typeAt: 1.2, x: 400, y: 650, size: 24 },
]
```

| 項目 | 意味 |
|---|---|
| `kind` | `box`（枠つきの四角）/ `window`（題名の帯つきの窓）/ `text`（文字だけ）/ `pill`（丸い札）/ `input`（入力欄）/ `button` / `bubble`（吹き出し） |
| `x`, `y`, `w`, `h` | 位置と大きさ（1600×900 の中の座標）。`w`, `h` は省くと中身に合わせる |
| `text`, `title` | 中の文字。`title` は `window` の題名 |
| `id` | カメラの寄り先、切り替えの出どころ・行き先に使う名前 |
| `at` | 出てくる秒 |
| `typeAt` | その秒から 1 字ずつ打つ（入力の様子） |
| `light` | 明るい画面（白い窓）の色にする。モック画面に使う |
| `color`, `size`, `bold`, `align`, `dashed` | 枠の色、文字の大きさ、太字、寄せ、点線 |
| `css` | ほかの見た目を CSS で足す |

あとに書いたものほど手前に出る。窓の上に重ねるものは、窓より後に書く。
