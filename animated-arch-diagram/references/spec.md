# spec.js の書式

`window.SPEC = { ... }` に次の項目を書く。座標・時刻の計算はすべて engine.js がやるので、ここには「何があって、何が起きるか」だけを書く。

## 全体

| 項目 | 必須 | 意味 |
|---|---|---|
| `title` | | 左上の見出し（無ければ図が上に詰まる） |
| `subtitle` | | 見出しの下の一行 |
| `grid` | | `[列数, 行数]`。既定 `[3, 3]`。画面（1600×900 の論理座標）の図の領域をこの升目に割る |
| `gap` | | ノードが1つずつ現れる間隔（秒）。既定 0.18 |
| `fps` | | 既定 30（X 推奨）。60 にすると滑らかだがファイルが倍 |
| `theme` | | `{ bg, card, fg, dim, edge, dot, font, mono }` の一部だけ上書きできる |
| `nodes` | ✓ | 下記。**並び順 = 登場順** |
| `edges` | ✓ | 下記 |
| `steps` | ✓ | 下記。上から順に再生 |
| `outro` | | `{ caption, kicker, hold }`。締めの一言、その上の小見出し、滞在秒（既定 2） |

## nodes

```js
{ id: 'worker', label: 'worker', sub: 'gpt-6.1-sol', tag: 'medium', color: '#f59e0b', col: 1, row: 1, w: 280 }
```

| 項目 | 必須 | 意味 |
|---|---|---|
| `id` | ✓ | edges / steps から参照する名前 |
| `label` | ✓ | カードの大きな文字（27px 太字）。日本語可 |
| `sub` | | カードの小さな文字（等幅 16px）。モデル名・技術名など |
| `tag` | | 右上のピル（high / medium / v2 など） |
| `color` | ✓ | 枠・左の帯・光・粒の色。**同じ種類は同じ色** |
| `col`, `row` | ✓ | 升目の位置（0 始まり、小数可。`col: 1.5` で2列目と3列目の真ん中） |
| `w`, `h` | | カードの幅・高さ（既定: 幅 min(280, 升目幅−40)、高さ 88） |

## edges

```js
{ from: 'main', to: 'architect', dashed: true, label: 'on demand' }
```

- 行が違えば上下の辺どうしを S字で、同じ行なら左右の辺どうしを直線で結ぶ。
- `dashed: true` は常時ではない呼び出し（流れる点線になる）。
- `label` は線の中ほどに小さく出る（多用しない）。
- flow では向きは自由（`['architect', 'main']` と書けば逆向きに流れる）。

## steps

```js
{
  kicker: 'ARCHITECT',           // 字幕の上の小見出し（番号は自動で付く: "05  ARCHITECT"）
  caption: 'Astra を呼ぶのは3回だけ',  // 字幕（タイプライター）
  focus: ['main', 'architect'],  // 明るく光らせるノード。無ければ全部ふつうの明るさ
  flow: [['main', 'architect'], ['architect', 'main']], // 順番に流れる区間。尺がある限り繰り返す
  hop: 0.55,                     // 1区間を流れる秒（既定 0.8）
  dur: 3.9,                      // このステップの滞在秒（既定 2.4）
  color: '#f472b6',              // 小見出しの色（既定: focus の最後のノードの色）
  badges: [                      // ノードの上に出すピル。同じノードの次のバッジが出るまで表示
    { node: 'architect', text: '① 計画の前', at: 0.3 },   // at = ステップ開始からの秒
    { node: 'architect', text: '② 同じエラー', at: 1.6 },
  ],
}
```

- 流れの1周 = 区間数 × hop + 0.35 秒。`dur` の中に収まらない便は出さないので、往復を3回見せたいなら `dur ≥ 3 × (2 × hop + 0.35) + 0.45` にする。
- バッジを3つ出すステップは `dur` を 3.5〜4 秒に伸ばす（1つ 1.2 秒以上見せる）。
