# 歌詞スクロール動画を作る

mp3 1 本から、SNS に載せられる縦長の動画を作る。
動画は同梱の `scripts/make_lyric_video.py` が作る。歌詞を声に合わせる時刻は `scripts/align_lyrics.py` が出す。自分で動画処理を書き直さない。

## 必要なもの

- `ffmpeg` と `ffprobe`
- Python 3.9 以上と Pillow
- `uv`。歌詞を声に合わせるときに使う。初回は faster-whisper を PyPI から、聞き取り用のデータ（medium）を Hugging Face から取ってくる
- 日本語フォント。macOS はヒラギノ角ゴシックを自動で使う。見つからない環境では `--font-bold` と `--font-regular` で指定する。

## 手順

1. mp3 のタグを確かめる。歌詞（`lyrics-***` のタグ）とジャケット画像が入っているかを見る。

   ```bash
   ffprobe -v error -show_entries format_tags=title,artist:stream=codec_type -of default=nw=1 "<mp3>"
   ```

2. 歌詞がある曲では、声を聞き取って、行ごとの歌い出しの時刻を出す。1 分半の曲で 1 分ほどかかる。

   ```bash
   uv run <このスキルのフォルダ>/scripts/align_lyrics.py "<mp3>" -o timings.json --words words.json
   ```

   - 行ごとの歌い出しの時刻、歌い終わりの時刻、聞き取りと合ったかの ○× が画面に出る。× の行は、前後の行から割り振った時刻になっていて、歌い終わりの時刻は無い。
   - 歌い終わりから次の行の歌い出しまでが 4 秒より長い所は、間奏として扱われる。間奏のある曲では、その場所が実際の間奏と合っているかを見る。
   - ランダムに 5 行ほど選び、`words.json` のその時刻の言葉が歌詞と合っているかを見る。
   - `--lyrics` で歌詞を差し替えるときは、ここでも同じファイルを渡す。行の数が合わないと、次の手順で止まる。

3. 1 枚だけ書き出して、見た目をユーザーに見せる。曲の途中の秒を指定すると、歌詞が流れている画になる。

   ```bash
   python3 <このスキルのフォルダ>/scripts/make_lyric_video.py "<mp3>" -o preview.png --preview 30 --timings timings.json
   ```

4. ユーザーがよければ、動画を書き出す。2 分半の曲で 1 分ほどかかる。

   ```bash
   python3 <このスキルのフォルダ>/scripts/make_lyric_video.py "<mp3>" -o "<mp3 のファイル名>_lyric.mp4" --timings timings.json
   ```

   - 歌詞の流し方は 2 つある。どちらにするかは、ユーザーに聞く。
     - `--timings timings.json` だけを渡すと、1 行ごとに声に合わせる。行によって流れる速さが変わる。
     - `--timings timings.json --even` を渡すと、イントロの間は歌詞を止め、最初の行を歌い出す秒から最後の行を歌い出す秒までを、一定の速さで流す。
   - 出力の名前は、曲名ではなく mp3 のファイル名から付ける。Suno は同じ曲名の mp3 を何本も出すので、曲名で付けると別の版の動画を上書きする。
   - 同じ名前の動画がもうあるときは、上書きせず、別の名前にする。

5. 書き出した動画から数枚を切り出して、歌詞の最後の行まで画面に出ているかと、その時刻に歌っている行が歌詞の枠の上から 3 行目にあるかを確かめる。間奏のある曲では、間奏の始めと終わりの 2 枚を切り出して、歌詞が同じ位置で止まっているかも見る。

## オプション

| オプション | 使う場面 |
|---|---|
| `--bg dots` / `grain` / `blur` / `tiles` | 背景を選ぶ。指定が無ければ `dots`。中身は下の「背景」の表 |
| `--lyrics 歌詞.txt` | mp3 に歌詞が無いとき、または歌詞を直したいとき。mp3 の歌詞より優先する |
| `--timings timings.json` | 歌詞を声に合わせて流すとき。`align_lyrics.py` が書き出した JSON を渡す |
| `--even` | `--timings` と一緒に使う。イントロの間は歌詞を止め、歌い出しから最後の行までを一定の速さで流す |
| `--start 秒` / `--end 秒` | `--timings` を使わずに、歌詞を流し始める秒と流し終える秒を手で決めるとき。`--start` にイントロの長さを入れる。`--end` の指定が無ければ曲の終わり |
| `--no-lyrics` | 歌詞を出したくないとき。ジャケットを大きく出す |
| `--title` | 曲名を変えたいとき |
| `--cover 画像` | ジャケットを別の画像に差し替えたいとき。mp3 に入っているジャケットより優先する。背景の色もこの画像から作る |
| `--artist` | 「by 〜」の名前を変えたいとき。指定が無ければ `musoukun` を出す。mp3 のタグの名前（Suno のユーザー名）は使わない。`--artist ""` で名前を消す |
| `--max-mb 数` | 投稿先にファイルの大きさの上限があるとき。動画がこの大きさを超えたら、すぐ下に収まるように映像を圧縮し直す。上限が 50MB なら `--max-mb 49` を渡す。1MB は 1,000,000 バイトで数える |
| `--preview 秒` | その秒の画を png で 1 枚だけ出す |
| `--fps` | 初期値は 30 |

## 歌詞の扱い

- `[Verse 1]` や `[soft chords, no drums]` のように、行全体が角括弧の行は外す。Suno の歌詞には歌わない指示が角括弧で入っているため。
- 歌っている行は、歌詞の枠の上から 3 行目に来る。
- `--timings` を渡すと、歌詞は行ごとの歌い出しの時刻に合わせて流れる。行と行の間は一定の速さでつなぐ。
- `--timings` と `--even` を渡すと、歌詞は最初の行の歌い出しまで止まり、そこから最後の行の歌い出しまでを一定の速さで流れる。
- `--timings` を渡すと、間奏の間は歌詞が止まる。前の行を歌い終わるまでに次の行が上から 3 行目に来て、次の歌い出しまでそこで待つ。`--even` を付けたときは、間奏で区切った区間ごとに一定の速さで流れる。
- 間奏とみなすのは、歌い終わりから次の歌い出しまでが 4 秒より長い所。秒数を変えたいときは、`make_lyric_video.py` の `PAUSE_SEC` を直す。
- `--timings` を渡さないと、歌詞は曲の頭から終わりまでを一定の速さで流れる。イントロがある曲では、歌が始まる前から歌詞が流れて、声と合わない。イントロの長さが分かっているなら `--start` に入れる。
- イントロの長さは、音の大きさからは分からない。Suno の曲は頭からビートが鳴っているため。`align_lyrics.py` で声を聞き取って出す。
- 時刻は `align_lyrics.py` が faster-whisper で声を聞き取って出す。mp3 の歌詞と実際に歌われた言葉が違う所は、近い言葉の時刻になるか、前後の行から割り振った時刻になる。
- 横幅に入らない長い行は、文字の途中で折り返す。

## 見た目の決まり

- 上から、曲名、「by musoukun」、ジャケット、歌詞 6 行の順に並ぶ。
- 歌詞は上の端で消えていき、下の端では薄く出てくる。
- 波形は、歌詞の下から画面の下のほうにかけて、白の半透明で出る。
- 見た目を変えたいときは、スクリプトの `make_foreground`（曲名とジャケットの配置）、`bg_layer`（背景）、`build` の中の `showwaves`（波形）を直す。

## 背景

ユーザーが背景を指定しなければ `dots` を使う。どの背景もジャケットの色から作るので、曲ごとに色が変わる。

| 指定 | 見た目 | 動き |
|---|---|---|
| `dots`（初期値） | ジャケットを縦横のマス目に縮め、1 マスを 1 つの丸い点で描く。電光掲示板のような見た目 | 点の並びがゆっくり上に流れる |
| `grain` | ジャケットでよく使われている 2 色の、上から下へのグラデーション | フィルムのような細かい粒が毎フレーム変わる |
| `blur` | ジャケットの色を大きくにじませた画像。Suno の公式動画に近い | ゆっくり上下左右に揺れる |
| `tiles` | 小さく暗くしたジャケットをタイルのように敷き詰める | 斜めにゆっくり流れる |
