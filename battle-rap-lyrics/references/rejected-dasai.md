# ダサいと言われたフレーズ

ユーザーに「ダサい」「最悪」「酷い」「パンチが弱い」と言われて、外したフレーズを集めた。
書く前に読み、同じ形のフレーズを出さない。

- ここの行は、外した行。そのまま使わない。似た形も使わない。
- 本人が分かる地名は「〇〇」に伏せた。

## 1. 地名や名所のだじゃれ、観光の絵はがきに頼る

言葉遊びの仕掛けが見えすぎて、安く聞こえる。

```
京都と聞けば 都
着いたら 雪の 〇〇
```

```
絵はがきなら 〇〇（名所）
俺には 雪の 立ち往生
```

- 地名の 1 音違いや、名所の名前の字を掛けるだけの行は書かない。

## 2. 「AなのにBは〜」の、気の利いたふうの対比

ひねった感じを出そうとした対比が、生活の不満を弱くしている。

```
ボンベは来るのに 業者は来ない
火はボンベ 呼べる手は無い
```

- 生活の不満は、対比で飾らずに本音を直球で言う。採用された形は「高すぎる」とそのまま言う行だった。

## 3. どこかで聞いた、きれいで中身の無い締め

歌詞らしく聞こえるだけで、何も言っていない。

```
届かない声 止まらない手
答え合わせは まだ先
居場所は もらうもんじゃない 組むもん
鍵かける手で 鍵のいらないもん作る
下げない頭 今度は俺の番
```

```
制服脱げば 集中 作るのに夢中
格子の向こうは不自由 俺の頭は自由
選んだ道は まだ途中
捨てた道は ひとつで十分
```

- 「まだ先」「まだ途中」「止まらない」「〜じゃない 〜もん」「今度は俺の番」のような決まり文句で締めない。
- 2 つ目の 4 行は、「変えてほしい」と言われた。韻をそろえるために、どこかで聞いた締めの言葉を並べていた。
- 仕事の道具と、作ることを掛ける行は、よく聞く形になる。

## 4. 弱い言い返し

相手に言い返す行が、おとなしくて当たらない。

```
そっちは 聞く耳が足りない
```

- 採用された形は「黙れよ お前は〜足りねえ」。相手に直接ぶつけ、語尾を崩す。

## 5. 意地の張り合いを、ことわざのように言う

```
頑固には頑固 根比べなら負けねえ
```

- 「〜には〜」「〜なら負けねえ」の形は、決まり文句に聞こえる。

## 6. 悲壮感で強さが薄れる

```
業者は来ねえ 春も来ねえ
```

- 戦っている曲で、季節や天気に頼って寂しさを出さない。強さが薄れる。

## 7. 説明だけの行、言い直すだけの行

```
決まってた線路を 降りて 別の道
辞める扉は 開いたまま
その扉に 背中 向けたまま
俺は 詫びの代わりに 割られた頭
学校と引っ越し 同じ日付
```

- 「別の道」は、どこへ行ったかが分からない。
- 扉の 2 行は、次の行の「それでも制服を着る」を別の例えで言い直しているだけだった。
- 「詫びの代わりに」は、説明の言葉。採用された形は「俺は 割られた頭」だけだった。
- 「学校と引っ越し 同じ日付」は、「微妙」と言われた。事実をそのまま並べただけで、絵も韻も無い。

## 8. 行の中で踏んでいない

```
名前は練習 中身は暴行
止まらねえ拳 ただの横暴
```

- 行の終わりが前の行とそろっていても、1 行の中で踏んでいないと弱い。「イン踏んでない」と言われた。
- 1 行の前半と後半の言葉の母音をそろえる。採用された形は、前半の言葉を、後半と同じ母音の言葉に替えたものだった。
