# 仕組みを説明する動画（MP4 / GIF）

成果物は MP4（1920×1080、30fps、H.264）と GIF（15MB 以下）とポスター画像。

## 基本の形

実例を 1 回、操作として見せる。
解説したい瞬間で時間を止め、その裏の仕組みに入る。
仕組みを見せ終えたら操作に戻る。

| 順 | 場面 | 見せること |
|---|---|---|
| 1 | 全体の形 | 構成図を 1 回出す。AI やプログラムがいくつあるか、毎回同じもの・毎回変わるもの、繰り返しの 1 周を見せる |
| 2 | 操作 | モック画面で実例を操作する。カーソルが動いてクリックし、クリックや入力に合わせてズームする。実画面の録画でなくてよい |
| 3 | 仕組み | 操作で出たもの（送った文字など）を、画面いっぱいに広げて引き出す。そのまま処理を動きで見せる（文字が区切られる、順位表の棒が伸びて並べ替わる、など）。構成図は、いま話している部分だけを差し込む |
| 4 | 2 と 3 を繰り返す | 止めて解説したい瞬間の数だけ繰り返す |
| 5 | 締め | 伝えたい 1 文を字幕に出す |

- 字幕は、画面の下に小見出しと 1 行。
- 構成図だけを見せる短い動画（X に貼る 15〜25 秒の図解）を頼まれたときは、1 と 5 だけで作る。

## どんな動画でも守ること

- 最初に全体の形を見せる。
  見る人がつかむべき要点（AI はいくつか、毎回同じもの・毎回変わるもの、どこが繰り返されるか、など）を、要点 1 つにつき 1 つの場面で見せる。
- 毎回同じものと毎回変わるものは、見た目の決まりを 1 つ決めて分ける。
  たとえば、毎回同じものは同じ場所に置いたままにし、変わるものだけを入れ替える。
  決まりは動画の最後まで変えない。
- 前の結果が次の入力になるときは、そのつながりを動きで見せる。
- 1 つの場面で見せるのは 1 つ。ほかは消すか暗くする。
- 仕組みは、文章ではなく動きで見せる。
- 流れは上から下、または左から右にする。
  人が読む向きと同じだと、目で追いやすいため。
  戻る流れだけが逆向きになるので、繰り返しだと見て分かる。
- 画面に出す数字と例は、実データから取る。
- 原文だけを「」に入れる。言い換えた文は「」に入れない。
- 記録に無いこと（AI がどう考えたか、など）は推測で書かない。
- ファイル名・関数名・データの形は出さない。
  「〜を書いた文章」のように中身で呼び、何のためのものかを添える。
- 直しを頼まれたら、言葉どおりに書き足さない。
  何を伝えたいのかに戻って、場面から作り直す。
  書き足すと、画面の文字が増えて分かりにくくなる。

## 作る前に決めること

次の 5 つを決めて台本にする。
台本は作る前に見せて、承認をもらう。
台本の書き方は `references/storyboard.md`。

1. 伝えたい 1 文。締めの字幕になる
2. 見る人がつかむべき要点。3 つまで
3. 実例。使う例と、使わない例。依頼に書いてあれば従い、無ければ聞く
4. 実データの取り方。実際に動かして記録を取るか、残っている記録を読むか。
   説明しようとしている主張が、今の実物の動きと合っているかもここで確かめる。合わなければ、作る前に聞く
5. 止めて解説する瞬間。3〜5 か所

## 手順

小さく作って、毎回画像で確かめる。

### 0. 環境

- `ffmpeg -version` と `node --version` で入っているかを見る。
- Playwright のブラウザは、先にキャッシュを見る（Mac: `~/Library/Caches/ms-playwright`、Windows: `%LOCALAPPDATA%\ms-playwright`）。
  テンプレートの `playwright-core@1.59.1` は `chromium-1217` に合う。別の版しかなければ `package.json` の版を合わせる。
  `render.mjs` は、キャッシュの新しい Chromium、インストール済みの Chrome の順に探す。

### 1. 台本を作り、承認をもらう

上の「作る前に決めること」を台本の表にして見せる。
承認が出るまで、次に進まない。

### 2. テンプレートをコピーして、台本を書き移す

```powershell
New-Item -ItemType Directory -Force "<作業フォルダ>" | Out-Null
Copy-Item -Recurse "<このスキルのフォルダ>\assets\template\*" "<作業フォルダ>"
cd "<作業フォルダ>"; npm install
node tools/render.mjs info    # 場面ごとの時刻表が出れば動いている
```

書き換えるのは `scenes.js`（台本）だけ。
テンプレートの `scenes.js` は見本（架空の問い合わせチャット）なので、書き方の見本として読んでから上書きする。
書式は `references/scenes.md`。

| ファイル | 役目 |
|---|---|
| `scenes.js` | 台本。場面の並び、字幕、カメラ、切り替え、場面ごとの中身 |
| `core.js` | 時刻 t の絵を描く。場面の並べ方、カメラ、切り替え、字幕 |
| `parts/*.js` | 場面の中身を描く部品。使う部品を `index.html` で読み込む |
| `index.html` | 上の 3 つを読み込むページ。ブラウザで開くとループ再生、`?t=12.5` でその時刻に止まる |
| `tools/render.mjs` | 1 コマずつ撮って、MP4 と GIF にする |

### 3. 止めた絵で確かめる

全体を等間隔に撮った一覧と、各場面の終わり近くの原寸の絵を撮り、Read ツールで開いて見る。
見るところは下の「確かめ方」。

```powershell
node tools/render.mjs sheet 16          # out/sheet.png（全体を 16 コマ、各コマに時刻入り）
node tools/render.mjs stills 4.4,9.4    # out/still-<秒>.png（原寸）
```

場面の切り替えは、途中のコマ（切り替えの始まりから 0.1、0.3、0.5 秒あたり）も撮って見る。

### 4. 書き出す

```powershell
node tools/render.mjs video <名前>
ffprobe -v error -show_entries stream=width,height,r_frame_rate,nb_frames -show_entries format=duration,size -of compact out/<名前>.mp4
```

- GIF は 15MB を超えたら、幅と fps を落として作り直す（960px/15fps、800px/12fps、640px/10fps の順）。
- X には MP4 を勧める。GIF は Slack・README・社内資料向け。
- ファイルを渡すツールがあれば MP4 と GIF を渡す。作業フォルダが消える場所なら、残す場所を聞く。

## 確かめ方

- 止めた絵だけを見て、要点に答えられるか（AI はいくつか、何が毎回同じか、どこが繰り返されるか、など）。
- どの場面でも、見るべきものが 1 つに絞れているか。
- 画面の数字・例・文が、実データと合っているか。
- 重なり・はみ出し・1 文字だけ次の行に落ちる文が無いか。中身がいちばん多い場面は必ず見る。
- フォント（Noto Sans JP）が効いているか。豆腐や明朝になっていないか。
- 最初と最後のコマがどちらも空で、つなげて流しても継ぎ目が無いか。

## 見た目を変えたいとき

- 色とフォントは、台本のファイルの `theme` で変える。
- 演出を足すときは、描く部品の中で「時刻 t から決まる値」として書く。
  `Math.random()` や `Date.now()` は使わない。使うと録画がガタつく。

## 描くときの落とし穴

| 症状 | 原因 | 対処 |
|---|---|---|
| つなげて流すと、継ぎ目で一瞬絵がちらつく | フェードの終わりと尺の終わりが同じだと、最後のコマにまだ絵が少し残る | フェードを尺より少し前（0.12 秒前）に終わらせる |
| 札や枠の幅が文字と合わない | フォントを読み込む前に文字の幅を測った | 使う文字を透明で一度置き、`document.fonts.ready` を待ってから測る |
| 点線が「引かれる」動きにならない | 線を引く動きも点線も stroke-dasharray を使うので両立しない | 点線はフェードで出し、流れる点線にする |
| 1 文字だけ次の行に落ちる | 幅ぎりぎりの文 | 文を縮めるか、文字を 1〜2 段小さくする |
| 場面の途中で撮った絵では、文が足りないように見える | 文は時間をずらして出るので、途中ではまだ出ていない | 各場面の終わり近くを撮る |
| 画面いっぱいに広がる・縮む切り替えで、前の場面が透けて見える | 場面の背景が透明だった | 場面ごとに背景を塗る（core.js でしている） |
| カメラが白い画面に寄ると、字幕が読めない | 白い文字が白い画面に重なった | 字幕を暗い帯の上に出す（index.html でしている） |
