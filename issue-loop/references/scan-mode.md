# スキャンモード（洗い出しだけ。実装しない）

「実装しなくていい」「A パターンですぐ実装できる issue だけ洗い出して」「簡単なやつリストして」のように、**着手せず候補を見たいだけ**のときはこのモードで動く。`/issue-loop --scan` でも入れる。

手順：

1. Step 1 で候補を取得する。Pre-flight は省略してよい。既定はタグ＝両方、列＝`Ready`＋`Backlog`。ユーザーが指定したらそれに従う
2. 各候補を軽く読み（Step 2 と同じ）、A/B 判定する
3. **A（すぐ迷わず実装できる）issue だけ**を表で出す

| # | タイトル | やること（1行） | 触るファイル目安 |
|---|---|---|---|

末尾に「B（曖昧で設計が要りそう）: N 件は除外」と1行添える（黙って捨てない）。判断に画像が要る issue は本文だけで A にせず、B 扱いにして「画像確認が要る」と書く。

ここで**止まる**。ブランチ・実装・PR には進まない。続けて着手するなら、出た番号を渡して通常フロー（Step 3 以降）を回す。
