# よく分からないと言われたフレーズ

ユーザーに「よく分からない」「事実と違う」と言われて、外したフレーズを集めた。
書く前に読み、同じ形のフレーズを出さない。

- ここの行は、外した行。そのまま使わない。似た形も使わない。

## 1. 自分で作った例えで、何の話か分からない

```
居場所は イス取りじゃねえ イス作り
```

- 例えの仕掛けを、聞き手が自分で解かないといけない行は書かない。聞いてすぐ、何の話か分かる言葉にする。

## 2. 相手のセリフへの答えが、事実とずれている

```
「何やってる？」 荷物と待ってる
```

- セリフを拾って返すときも、答えの中身はメモの事実に合わせる。韻のために、起きていない様子を答えにしない。

## 3. 言葉遊びのために、事実を作る

```
分身の術なら 夫婦で 二人いる
二手に分かれて ダブルで刺しに行く
```

- メモは「夫婦で戦っている」だった。「二手に分かれる」「刺しに行く」は、起きていない。
- 前のバースの言葉を回収したいときも、事実に無い動きを足さない。

## 4. やり方の言葉だけが残って、別の仕事の話に聞こえる

```
訓練のリングで 向かいは手加減ゼロ
```

- 訓練のやり方だった競技の言葉を残したので、その競技の選手の話に聞こえた。

## 5. した側と、された側が逆

```
俺は 開けた頭
```

- 頭を開いたのは本人ではない。「割られた」と、された形で書く。
