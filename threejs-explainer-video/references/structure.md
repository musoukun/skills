# 3D仕組み解説ショートの構成と演出

参考にした型: YouTube ショートの「装甲を貫く砲弾の進化」（縦 1080×1920・45秒・30fps）を 1秒1枚に分解して読んだもの。台本や絵は写さず、**型だけ**をここにまとめる。

## 構成の型（45秒・約15フレーズ）

| 段 | 役割 | 長さの目安 | 絵 |
|---|---|---|---|
| 1. 思い込み | 視聴者が信じていそうなことを言い切る＋「〜ですよね？」 | 4〜5秒 | 主役の物がかっこよく動く（飛ぶ・回る） |
| 2. 反転 | 「実は逆です」→ 本物を見せる | 4〜5秒 | **1 の続きの同じカット**。当たった（動いた）瞬間に時間が止まり、止まった世界をカメラが寄って、思い込みと違う本当の形（例: 丸い先端）を見せる。別の場所・別の物に切り替えない（同じ物の話だと伝わらなくなる） |
| 3. たとえ | 誰でも見たことがある現象（水切り・坂道・風船など） | 5〜7秒 | 舞台をがらっと変える（屋内・水辺）。2つを並べて比べる |
| 4. 当てはめ | たとえと同じことが本題でも起きる | 5秒 | 失敗する方を先に見せる（弾かれる・割れる） |
| 5. 正解 | もう一方はうまくいく | 5秒 | 同じ構図・同じカメラで成功を見せる（比べやすい） |
| 6. 問題 | 「しかし、ここで問題が」 | 5秒 | 新しい弱点を絵で（空気の壁・熱・重さ） |
| 7. 解決 | 「そこで〜を付けました」 | 4〜5秒 | 部品が取り付く。断面で中を見せる |
| 8. 仕組み | 解決策がどう働くかをスローモーションで | 5〜6秒 | 衝突・破壊・爆発。カメラを揺らす |
| 9. 名前の回収 | 「こうして生まれたのが〇〇です」 | 4〜6秒 | 完成品をゆっくり回す。部品に名札 |

- 1〜2段で「え？」と思わせ、3段で「分かる」、4〜5段で「なるほど」、6〜7段でもう一度ひねる。**ひねりを2回**入れると45秒が持つ。
- 最後に正式名称（日本語＋略号）を出すと、検索・コメントのきっかけになる。

## カットと字幕

- 1カット 3秒前後。字幕のフレーズが変わるたびに、カメラの向きか寄りを少し変える（同じ物でも退屈しない）。
- 字幕: 白・太字・黒い影。画面の**中央やや下（高さの 60〜65%）**。1枚に1〜2行、1行12〜14字。読点で区切ってフレーズごとに出す。
- 背景は浅いピント（被写界深度）でぼかし、物だけをくっきり。砂漠・霧・暗いスタジオなど、色数の少ない舞台が字幕を読みやすくする。
- 物は**画面の上半分**に置くと、字幕と重ならない。

## よく使うカット

| カット | Three.js での作り方 |
|---|---|
| 並走（物が飛ぶ横をカメラが一緒に動く） | 物の x を t で進め、`shot.fit(物の位置, 幅, 向き)` を毎コマ呼ぶ。`streaks` で速さを出す |
| スタジオで寄る | 暗いグラデーション背景＋キーライト＋青い逆光。`fit` の幅を小さくしながら向きを回す。**部品の取り付け・断面・名前の回収など、場面と切り離して形だけを見せたいときに使う**（反転には使わない） |
| 比べる（失敗 → 成功） | 同じ舞台・同じカメラの関数を2カットで使い、物だけ替える |
| 取り付く | 部品を離れた位置から `ease.outBack` で滑り込ませる |
| 断面 | `cutaway(部品, new THREE.Plane(法線, 定数))`。定数を t で動かすと、切れていく様子が見える |
| 衝突のスローモーション | 当たる時刻 `tHit` を `ctx.cue()` から決め、前後で動きを場合分け。`burst`（火花・破片）＋`fireball`＋カメラの揺れ |
| 時間停止 → 寄る（参考の「実は逆です」） | `timeWarp` / `slowToStop` で世界の時刻を当たった瞬間に止め、カメラだけ `camKeys` で寄る。火花と炎は `update(t, fade)` で止めたまま薄くする |
| 着弾から次の字幕まで1カットで続ける | 2つのシーン id で同じ組み立て関数を共有し、動画全体の時刻 T で動かす（例題の `strikeAndFreeze`） |
| 跳弾 | `findSlope` で傾斜面、`glance` で面に沿う向き。触れた瞬間に止めてから再開。宙返りさせない |
| 名札 | `ctx.label(位置, '文字', { offset: [dx, dy], alpha })`。offset は画面の内側に向ける |
