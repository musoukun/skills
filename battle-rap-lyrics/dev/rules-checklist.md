# スキルの指示と決まりのリスト

スキルを作り直すときに、指示が漏れていないかを確かめるためのリスト。
スキルを作り直したら、このリストの 1 行ずつについて、新しいスキルのどこに書いてあるかを確かめる。
消した決まりは、消した理由を「消した理由」の列に書く。

このファイルはスキルの本文ではない。歌詞を書くときには読まない。

作った日: 2026-11-21（コミット 4684012 の SKILL.md と references から作った）
