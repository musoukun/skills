# 実例 8 曲の分析

`references/lyrics/` の 8 曲を、`scripts/check_rhyme.py` で数え、1 曲ずつ読んで分けた。
歌詞を書く前に読むのは、この資料だけでよい。場所はファイル名と行番号で書いてある。中身を確かめたいときだけ、その行の前後を歌詞ファイルで開く。

対象は `jimoto-love` `life-stash` `makkou-shoubu` `rep` `rgto` `221` `have-a-good-time` `ichimou-dajin` の 8 曲。

## 1. 数で見た韻

| 曲 | 行数 | 終わり ◎ の行 | ★ の行 | 7 個以上の ★ |
|---|---|---|---|---|
| jimoto-love | 59 | 18（31%） | 21（36%） | 5 |
| life-stash | 132 | 22（17%） | 10（8%） | 6 |
| makkou-shoubu | 110 | 10（9%） | 9（8%） | 0 |
| rep | 58 | 13（22%） | 13（22%） | 9 |
| rgto | 63 | 8（13%） | 5（8%） | 2 |
| 221 | 86 | 12（14%） | 18（21%） | 15 |
| have-a-good-time | 52 | 15（29%） | 12（23%） | 4 |
| ichimou-dajin | 45 | 6（13%） | 4（9%） | 0 |

- 長い韻は、毎行には無い。2 行の組で固まって出て、組と組の間には踏まない行がある。
- rep と 221 の 7 個以上は、ほとんどがフックの丸ごとのくり返し。フックを除くと、7 個以上は 1 曲に 0〜5 か所。

## 2. 長い韻の作り方は 6 つ

| 作り方 | 中身 | 場所 |
|---|---|---|
| 2 行を同じ形にして、高い物と安い物を並べる | 「高い物より／安い物」の形。自分の側は、安い物や地元の物にする | jimoto-love 15〜16 行（9 個）。have-a-good-time 14〜15 行（12 個） |
| 名前を片方に置く | 人や店や街の名前を先に決め、もう片方を普通の言葉で合わせる | 221 26〜27 行（人の名前）。have-a-good-time 5〜6 行（作曲家の名前）、45〜46 行（街の名前）。jimoto-love 36〜38 行 |
| 英語を口で言う音で踏む | 英語のつなげ読みを、日本語の言葉と合わせる | 221 25〜27 行（英語 3 語と人の名前で 7 個）。rgto 17〜21 行（「Like」と日本語の言葉で 6〜7 個） |
| 決まった言い回しをひっくり返す | ことわざの前と後ろを入れ替えて、元の言い回しと踏む | 221 5〜6 行（13 個） |
| 同じ形で、反対のことを言う | 「ここでは〜／よそから見れば〜」「〜で下がる／〜で上がる」 | jimoto-love 47〜48 行、58〜59 行 |
| 名詞を 4 つずつ並べる | 助詞を入れずに名詞を 4 つ並べ、次の行も同じ母音の名詞を 4 つ並べる | life-stash 40〜41 行（11 個） |

言葉を行の終わりで割って、次の行に続ける書き方もある（rep 25〜26 行、29〜30 行。life-stash 69〜70 行）。

## 3. 言いたいことを、物と名前に置き換える

実例は、気持ちを言う言葉（すごい、変わらない、強い）をほとんど使わない。聞き手が知っている物、人、名前に置き換えている。

| 言いたいこと | 実例の言い方 | 場所 |
|---|---|---|
| 売れても変わらない | 億万長者になっても、ストリートの服と靴を履く | 221 30 行 |
| 変わったのは暮らしだけ | 前はパトカーに追われ、今はベンツに乗る | 221 31〜32 行 |
| ラップの道具がそろっている | 書く道具の 3 つを、三種の神器と呼ぶ | 221 29 行 |
| 頂点に立った | スタープレイヤーの大谷翔平 | 221 40〜41 行 |
| もう敵がいない | ねたんでくるのは七福神くらい | 221 71〜72 行 |
| 仲間を増やした | 体にいい菌のように増えた | 221 69〜70 行 |
| 神のように見られている | CD を神棚に置き、参拝の作法をくり返す | 221 13 行、21〜24 行 |
| 地元が好き | 高級な焼肉店より、みんなと食うチェーン店 | jimoto-love 15〜16 行 |
| 都会のおしゃれに興味が無い | 都会の服屋、カフェ、雑誌の代わりに、地元の夜遊び | have-a-good-time 8〜10 行 |
| 昔は悪かったが、今は芸術家 | 逮捕続きから、有名な作曲家の名前へ | have-a-good-time 5〜6 行 |
| 熱い歌詞 | 「Like タイカレー」 | rgto 17 行 |
| 歌詞が速くて強い | マシンガン、スペースシャトル | ichimou-dajin 3 行、9〜12 行 |
| 戦い | ゲームの呪文と必殺技、ボクシング | makkou-shoubu 14〜15 行、26 行、52〜64 行 |
| 家族を大事にする | 英語の決まり文句を 1 字変える | rep 36 行 |
| 地元のストリート | ブーツのブランド、地元の球団の帽子 | rep 21 行、59 行 |

ここから分かる規則性は 3 つ。

- 借りる世界は、話と離れていてよい。野球、神様、菌、作曲家、ゲーム、食べ物から借りている。
- ただ、借りた名前と言いたいことのつながりは、聞いてすぐ分かる。大谷翔平は一番の選手、七福神はめでたい神様、菌は増える物。
- 「Like 〜」「〜みたい」「まるで〜」で、名前 1 つに例える。
- その世界の人が好きな物の名前で、自分が誰かを伝える。

## 4. その世界の人が好きな物

3 章の 3 つ目の規則性は、その文化を知らないと使えない。歌詞に使う前に、ここから選ぶ。

| 種類 | 物 | 使いどころ |
|---|---|---|
| ストリートの服と靴 | ディッキーズのワークパンツ、ティンバーランドの黄色いブーツ、バンズのスニーカー、アディダスのジャージ、カンゴールの帽子 | 金持ちになっても、ストリートの側にいると言う |
| ラップの道具 | マイク、ペン、紙、ビート、ブース | 自分の仕事を、大きな名前に例える |
| 成り上がりの印 | ベンツ、リムジン、億万長者 | 前は何だったかと並べて、変わった所を言う |
| 格を示す名前 | 大谷翔平、イチローのような、誰でも知っている一流の人 | 自分の格を、名前 1 つで言う |

題材の世界の物がここに無ければ、Web で「〜 定番」「〜 好きな物」「〜 あるある」のように調べ、名前を 10 個ほど集めてから選ぶ。調べずに思いつきで書かない。

服と靴の名前は、Web 検索の結果の要約で、ヒップホップの定番として出たものと、221 と rep に出てくるものから選んだ。記事の本文までは開いていない。

## 5. フック

フックは、長いフレーズを丸ごとくり返す（rep 8〜11 行、221 21〜24 行、jimoto-love 61〜64 行、have-a-good-time 33〜34 行）。同じフレーズをくり返してよいのは、フックだけ。

## 6. 1 行の組み立て

221 と have-a-good-time を 1 行ずつ読んで、1 行に何を入れているかを数えた。

| 数えたこと | 結果 |
|---|---|
| 1 行の音の数（「ー」「っ」「ん」も 1 音） | 221 は真ん中が 13 音、半分の行が 9〜16 音。have-a-good-time は真ん中が 14 音、半分の行が 12〜16 音 |
| 1 行に置く名前や物 | ほとんどの行が 1 つ。残りは普段の話し言葉 |
| カタカナや英語の言葉 | 短くて、誰でも知っている物の名前。スタバ、ビームス、ベンツ、ギャル、システム |

形は、話し言葉の短い前置きの後に、名前を 1 つ置く。前置きは「〜なら」「〜でも」「〜じゃ」「〜と言や」で、次の名前を引き立てる。

| 前置き | 置いた名前 | 場所 |
|---|---|---|
| 友達なら | 人の名前 | 221 26 行 |
| 億万長者でも | 靴と服のブランド | 221 30 行 |
| 変わったと言や | パトカーからベンツ | 221 32 行 |
| このゲームじゃ | スタープレイヤー | 221 40 行 |
| でも今ラップする | チャイコフスキー | have-a-good-time 6 行 |
| ラジオじゃ | 週間チャート | have-a-good-time 38 行 |

2 行で対にするときは、同じ形の普通の文を 2 つ並べる。「お前は」と「俺等」で始め、場所と動きを入れ替える（have-a-good-time 9〜10 行）。
